## Pinned work

**[Psychological-Bias-Transfer](https://github.com/coenhewes/Psychological-Bias-Transfer)** · *research in progress*
A controlled study of whether fine-tuning on distress-style language shifts a base LLM's outputs toward rumination, catastrophizing, doom framing and certainty collapse, and whether that is lexical style transfer or something more structural. Matched treatment/control corpora, replicated seeds, a dual-judge framework, and a mandatory null-results branch. Interim 3-seed results on Llama-3.1-8B are in the repo; the full 5-seed, two-model run is still going.

**[Forge](https://github.com/coenhewes/Forge-coding)** · *long-horizon coding agent*
An open-source (MIT) coding agent that turns an engineering task into a verified, reviewable pull request through a repo-aware harness: a semantic MCP fabric, durable task state, a risk model and verification gates. On one long-horizon benchmark task against opencode (same model, 3 runs each) quality tied and Forge used about 2.2× fewer main-model tokens. Design quality is a known gap, and the larger Forgeflow benchmark is still in progress. The README reports all of this plainly.

**[forgeblog](https://github.com/coenhewes/forgeblog)** · *open-source template*
A Next.js blog template with scheduled publishing and a machine-readable skill layer (`/skill.md` + `/skill.json`) so any LLM agent can write and schedule posts. Running in production on two sites.
