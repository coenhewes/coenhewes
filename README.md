### Pinned work

- **[Forge-coding](https://github.com/coenhewes/Forge-coding)** · *long-horizon coding agent* — An open-source (MIT) coding agent that turns an engineering task into a verified, reviewable pull request through a repo-aware harness: semantic MCP fabric, durable task state, a risk model, and verification gates. Benchmarked against opencode (same model, 3 runs each), quality tied while Forge used ~2.2× fewer main-model tokens.
- **[forgeblog](https://github.com/coenhewes/forgeblog)** · *open-source template* — A Next.js blog template with scheduled publishing and a machine-readable skill layer (`/skill.md` + `/skill.json`) so any LLM agent can write and schedule posts. Running in production on two sites.
- **[Psychological-Bias-Transfer](https://github.com/coenhewes/Psychological-Bias-Transfer)** · *research in progress* — A controlled study of whether fine-tuning on distress-style language shifts a base LLM's outputs toward rumination, catastrophizing, doom framing, and certainty collapse, and whether that is lexical style transfer or structural. Uses matched treatment/control corpora, replicated seeds, a dual-judge framework, and a mandatory null-results branch (interim 3-seed Llama-3.1-8B results live; 5-seed two-model run in progress).
